Ma Bibliothèque — Outil d'import Supabase

Outil autonome — accessible depuis les réglages de l'application (mode propriétaire), ou directement par un double-clic sur ce fichier. Il tourne entièrement dans ton navigateur et ne communique qu'avec ton propre projet Supabase — jamais avec Claude.

⚠️ La clé service_role donne un accès total à ta base (lecture/écriture/suppression, sans aucune restriction). Ne la partage avec personne d'autre que toi-même, et ne colle jamais ce fichier rempli quelque part en ligne. Elle reste uniquement dans la mémoire de cette page — elle n'est ni sauvegardée, ni envoyée ailleurs qu'à l'adresse Supabase ci-dessous.

1Connexion à Supabase

Tu la retrouves dans Supabase Studio → Project Settings → API → service_role (secret).

2Importer/mettre à jour des auteurs

Colle un tableau JSON d'auteurs, ou choisis un fichier .json. Format attendu : [{"name": "Jean Dupont", "name_sort": "Dupont Jean"}, ...]. Les auteurs existants (même name) sont fusionnés, pas dupliqués.

3Importer/mettre à jour des livres

Colle un tableau JSON de livres, ou choisis un fichier .json. Format attendu par élément : {"author_name": "...", "title": "...", "has_ebook": true, "has_pdf": false, "has_audio": false, "genre": "...", "openlibrary_subjects": [], "source_note": "...", "needs_review": false, "cover_i": 12345} (les champs genre/openlibrary_subjects/source_note/needs_review/cover_i sont optionnels). L'auteur doit déjà exister (importe-le d'abord à l'étape 2 si besoin) — author_name doit correspondre exactement au name de l'auteur dans Supabase. Les doublons (même auteur + même titre) sont automatiquement ignorés, tu peux relancer l'import sans risque. Si un cover_i (identifiant de couverture Open Library) est fourni, la couverture correspondante sera aussi téléversée automatiquement après l'insertion du livre.

4Re-téléverser des couvertures seules

Pour ajouter/remplacer des couvertures sur des livres déjà présents. Format attendu : [{"title": "...", "author_name": "...", "cover_i": 12345}, ...] — l'outil retrouve le livre par auteur+titre exact, télécharge la couverture depuis Open Library, la dépose dans le bucket covers, et met à jour cover_path sur le livre.

5Rechercher automatiquement les couvertures manquantes

Recherche sur Open Library une couverture pour chaque livre qui n'en a pas encore. La recherche porte sur le titre seul, puis l'auteur est vérifié dans les résultats : sur un échantillon de 50 livres de la base, cette méthode en retrouve 22 contre 6 pour l'ancienne. Open Library étant surtout alimenté en éditions anglaises, beaucoup de propositions porteront un titre anglais : c'est le même ouvrage, mais seule la vignette permet de le confirmer, d'où le niveau « probable », affiché mais laissé décoché. Clique sur une vignette pour l'agrandir. Rien n'est modifié tant que tu n'as pas coché puis cliqué sur « Téléverser la sélection » — tu vois chaque couverture proposée avant de l'appliquer.

6Ajouter une couverture trouvée ailleurs (manuel)

Pour les livres où même la recherche élargie (étape 5) ne trouve rien sur Open Library. Trouve toi-même une image de couverture (Fnac, Amazon, Babelio, une recherche d'images…), enregistre-la sur ton ordinateur (clic droit → « Enregistrer l'image sous »), puis dépose-la ici — pour ta bibliothèque strictement personnelle, pas pour republier l'image ailleurs.

7Mettre à jour des livres déjà en base (champs choisis)

Pour modifier certains champs d'un livre déjà présent, sans toucher aux autres — par exemple activer has_audio quand tu ajoutes la version audio d'un livre que tu as déjà en ebook. Format attendu : [{"author_name": "...", "title": "...", "fields": {"has_audio": true}}, ...] — author_name et title doivent correspondre exactement à ce qui existe déjà en base (l'outil retrouve le livre par cette combinaison exacte, comme pour les autres sections). Les entrées non trouvées sont listées sans rien modifier.

8Requête personnalisée (avancé)

Pour un correctif ponctuel que les sections ci-dessus ne couvrent pas. Exemple : PATCH /rest/v1/books?title=eq.Un+Monde+Sans+Fin avec le corps {"genre": "Historique"}. À utiliser avec précaution — ceci parle directement à ta base avec les pleins pouvoirs.

9Importer un lot de couvertures (fichiers nommés par identifiant)

Pour associer d'un coup plusieurs couvertures trouvées ailleurs (Fnac, Amazon, Babelio…) — typiquement un lot préparé par Claude. Chaque image doit être nommée exactement <identifiant du livre>.jpg (ou .png/.webp) ; l'identifiant est donné avec le lot, pas besoin de taper l'auteur ni le titre — ça évite toute confusion entre deux livres qui se ressembleraient. Sélectionne toutes les images du lot d'un coup (Ctrl/Cmd-clic, ou glisser-déposer plusieurs fichiers dans le champ).
